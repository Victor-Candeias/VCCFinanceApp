# S3-07: Rótulo Movimentos numa só linha na barra inferior

## Problema

Na barra inferior (`NavigationBar`), o rótulo **"Movimentos"** quebra para 2 linhas em ecrãs estreitos/fonte maior,
desalinhando os 5 destinos (Início, Contas, Movimentos, Relatórios, Mais).

Origem: `app/src/main/java/pt/vcc/financeapp/navigation/AppNavHost.kt:41` — `label = { Text(text = label) }` sem limite de linhas;
texto em `app/src/main/res/values/strings.xml:6` (`nav_transactions`).

## Solução proposta

- Forçar uma linha no rótulo: `Text(text = label, maxLines = 1, softWrap = false, overflow = TextOverflow.Ellipsis)`.
- Se ainda não couber, reduzir ligeiramente o estilo do rótulo (ex.: `MaterialTheme.typography.labelSmall`) para todos os destinos, mantendo consistência.
- Manter o texto "Movimentos" (sem abreviar), salvo se não couber mesmo assim; nesse caso validar alternativa com o utilizador.

## Critérios de aceitação

- [ ] "Movimentos" aparece numa só linha na barra inferior no emulador/dispositivo de referência.
- [ ] Os restantes rótulos continuam numa linha e alinhados.
- [ ] Sem truncagem visível com o tamanho de fonte por omissão; com fonte grande (acessibilidade) aplica-se reticências em vez de 2 linhas.
- [ ] `contentDescription`/acessibilidade mantém o texto completo.
